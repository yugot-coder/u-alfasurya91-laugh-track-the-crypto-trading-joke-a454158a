One original one-line joke about crypto and trading life, written to get
the biggest laugh from a judge that compares jokes two at a time. The line
takes the most universal trader ritual — buying the dip — and turns it
into a building going down: the dip has a basement, a sub-basement, and a
parking garage. One read, one escalation, punchline on the last word.

> I bought the dip. Turns out the dip had a basement, a sub-basement, and a parking garage.

## Run it

```sh
python3 main.py
```

This writes the joke to `entry.txt` (and to `/output/entry.txt` when that
directory exists), verifies the write by reading it back byte-for-byte, and
prints its sha256.
